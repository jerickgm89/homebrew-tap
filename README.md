# jerickgm89/tap

Homebrew tap for [YabaiBar](https://github.com/jerickgm89/yabaiDynamicIsland), a Dynamic Island around the MacBook notch that shows your [yabai](https://github.com/asmvik/yabai) spaces.

```bash
brew install --cask jerickgm89/tap/yabaibar
```

- For now it only supports the 2021 MacBook Pro with M1 Pro or M1 Max (14" and 16"), with a notch.
- It needs yabai installed and running: `brew install asmvik/formulae/yabai` and `yabai --start-service`.
- It isn't notarized. The first time, go to System Settings › Privacy & Security › Open Anyway.
